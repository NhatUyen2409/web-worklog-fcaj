5. Bài thực hành: Truy cập S3 an toàn qua VPC Endpoints

Bài thực hành chuyên sâu về AWS PrivateLink, Gateway & Interface Endpoints

5.1 Tổng quan & Kiến trúc bài thực hành

AWS PrivateLink cung cấp kết nối riêng tư an toàn tới các dịch vụ AWS từ VPC và mạng On-premises nội bộ mà không cần đưa lưu lượng truy cập qua Internet công cộng.

Gateway VPC Endpoint

Sử dụng cho tài nguyên bên trong VPC truy cập vào Amazon S3 và Amazon DynamoDB. Định tuyến lưu lượng thông qua Route Table mà không phát sinh thêm chi phí theo giờ.

Interface VPC Endpoint

Được cấp phát Elastic Network Interface (ENI) với địa chỉ IP riêng trong Subnet của bạn. Hỗ trợ truy cập cả từ VPC lẫn mạng On-premises thông qua AWS Site-to-Site VPN hoặc Direct Connect.

5.2 Điều kiện tiên quyết & Chính sách IAM

Chính sách IAM quyền tối thiểu để khởi tạo tài nguyên CloudFormation và Transit Gateway:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ec2:*TransitGateway*",
        "ec2:*VpcEndpoint*",
        "ec2:*RouteTable*",
        "s3:*",
        "route53resolver:*"
      ],
      "Resource": "*"
    }
  ]
}

5.3 Truy cập S3 từ VPC (Gateway Endpoint)

Các bước thực hiện tạo Gateway Endpoint và kiểm thử kết nối riêng tư:

  1. Vào VPC Console > Endpoints > Chọn Create Endpoint.
  2. Chọn Service: com.amazonaws.us-east-1.s3 dạng Gateway.
  3. Gắn Route Table của VPC Cloud để tự động cập nhật route prefix S3.
  4. Kiểm tra lệnh từ EC2 instance: 
    aws s3 ls s3://<your-bucket-name>

5.4 Truy cập S3 từ On-Premises (Interface Endpoint)

Mô phỏng môi trường On-Premises kết nối qua strongSwan VPN và cấu hình Route 53 Resolver Rule:

# Kiểm tra phân giải DNS nội bộ từ On-Premises
nslookup s3.us-east-1.amazonaws.com

# Tải file qua Interface Endpoint riêng tư
aws s3 cp test-file.bin s3://<your-bucket-name>/ --endpoint-url https://bucket.vpce-xxxx.s3.us-east-1.vpce.amazonaws.com

5.5 Chính sách VPC Endpoint (Kiểm soát quyền truy cập)

Chính sách giới hạn chỉ cho phép truy cập vào duy nhất bucket yourbucketname-2:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "RestrictSpecificBucket",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:*",
      "Resource": [
        "arn:aws:s3:::yourbucketname-2",
        "arn:aws:s3:::yourbucketname-2/*"
      ]
    }
  ]
}

5.6 Dọn dẹp tài nguyên (Tối ưu chi phí)

  • Xóa Route 53 Hosted Zone s3.us-east-1.amazonaws.com.
  • Hủy liên kết Route 53 Resolver Rule myS3Rule khỏi VPC On-prem.
  • Xóa 2 CloudFormation Stacks: PLOnpremSetup và PLCloudSetup.
  • Empty và Delete các S3 buckets đã tạo trong bài lab.
